## Machine Learning: Your Actual Pipeline

Your project uses these 3 scripts in `FALSEDOOR/ml/`:

| Script | Purpose | When to Run |
|---|---|---|
| `feature_extraction.py` | Reads `cowrie.json` → extracts features → saves `data/extracted_features.csv` | After collecting Cowrie attack data |
| `train_model.py` | Reads `extracted_features.csv` → trains Random Forest → saves `random_forest_model.pkl` | After feature extraction |
| `random_forest_model.pkl` | **Already trained model** – your FastAPI uses this directly | Already done! Copy to new server |

**Attack Classes your model knows:**
- `Brute Force` (failed login attempts)
- `Command Execution` (shell commands run after login)
- `Malware Download Attempt` (wget/curl download commands)

## STEP-BY-STEP: Deploy to New Ubuntu Server

### STEP 1 — Prepare Your New Ubuntu

```bash
# Update system and install essentials
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv git curl nginx

# Install Node.js v22 LTS (to build the React dashboard)
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
```

---

### STEP 2 — Copy Your FALSEDOOR Files to New Ubuntu

From your Windows PC (via SCP, USB, or SFTP):

**Option A (Recommended — 1-File Zip Transfer):**
We have already packaged all required files into `FALSEDOOR_UBUNTU_PACKAGE.zip` (which contains `server/`, `static/`, `ml/`, `data/`, `var/`, and `etc/` with the old virtual environment excluded).

```bash
# Run this on Windows PowerShell to upload the zip:
scp "C:\Users\ELs\Downloads\UITM\FYP\terst\FALSEDOOR_UBUNTU_PACKAGE.zip" ubuntu@<new-server-ip>:~/

# On Ubuntu Server, extract it to your home directory:
cd ~
unzip FALSEDOOR_UBUNTU_PACKAGE.zip
```

**Option B — Direct SCP Folder Transfer:**
```bash
# Run this on Windows PowerShell:
scp -r "C:\Users\ELs\Downloads\UITM\FYP\terst\FALSEDOOR" ubuntu@<new-server-ip>:~/FALSEDOOR
```

**Option C — USB / External Drive:**
```bash
# On Ubuntu:
cp -r /media/ubuntu/USB_DRIVE/FALSEDOOR ~/FALSEDOOR
```

> 💡 **Notice:** `server/` with its web UI in `server/static/` is already included inside `FALSEDOOR/server/`!
> When you extract `FALSEDOOR_UBUNTU_PACKAGE.zip`, you have the full backend and frontend ready to run.

---

### STEP 3 — Reinstall Cowrie on New Ubuntu

Cowrie must be reinstalled fresh (its virtual env is not portable):

```bash
# Go into FALSEDOOR folder
cd ~/FALSEDOOR

# Remove the old (broken) virtual env from old server
rm -rf cowrie-env

# Recreate it fresh
python3 -m venv cowrie-env
source cowrie-env/bin/activate

# Install Cowrie dependencies
pip install --upgrade pip
pip install cowrie

# OR install from source (more stable):
pip install git+https://github.com/cowrie/cowrie.git

deactivate
```

Your `etc/cowrie.cfg` is already copied and configured — it tells Cowrie to log to `var/log/cowrie/cowrie.json`. No config changes needed!

---

### STEP 4 — Set Up iptables Port Forwarding (Port 22 → 2222)

```bash
# Redirect real SSH port 22 to Cowrie's port 2222
sudo iptables -t nat -A PREROUTING -p tcp --dport 22 -j REDIRECT --to-port 2222

# Make it permanent
sudo apt install -y iptables-persistent
sudo netfilter-persistent save

# Change your real SSH to a different port (e.g. 2022) so you don't lock yourself out!
sudo sed -i 's/#Port 22/Port 2022/' /etc/ssh/sshd_config
sudo systemctl restart sshd
```

### STEP 5 — Start the FastAPI Backend

```bash
cd ~/FALSEDOOR/server
chmod +x start_server.sh
./start_server.sh
```

You should see:


### STEP 6 — Build & Deploy the React Dashboard

```bash
# On Windows: build the dashboard (run in PowerShell)
# cd "API Integration Dashboard"
# npm install && npm run build

# Then copy the dist/ folder to Ubuntu:
scp -r "dist" ubuntu@<server-ip>:~/falsedoor-web

# On Ubuntu: serve it with Nginx
sudo mkdir -p /var/www/falsedoor
sudo cp -r ~/falsedoor-web/* /var/www/falsedoor/
sudo chown -R www-data:www-data /var/www/falsedoor
```

---

### STEP 7 — Configure Nginx

```bash
sudo nano /etc/nginx/sites-available/falsedoor
```

Paste:
```nginx
server {
    listen 80;
    server_name _;

    root /var/www/falsedoor;
    index index.html;

    # React PWA (single page app)
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Proxy to FastAPI backend
    location /api/ {
        proxy_pass http://127.0.0.1:8000/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
    }
}
```

Enable and start:
```bash
sudo rm -f /etc/nginx/sites-enabled/default
sudo ln -s /etc/nginx/sites-available/falsedoor /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl restart nginx
```

---

### STEP 8 — Start Cowrie Honeypot

```bash
cd ~/FALSEDOOR
source cowrie-env/bin/activate
bin/cowrie start

# Check it's running
bin/cowrie status

# Watch live logs
tail -f var/log/cowrie/cowrie.json
```

---

### STEP 9 — (Optional) Keep FastAPI Running After Reboot

```bash
sudo nano /etc/systemd/system/falsedoor-api.service
```

Paste:
```ini
[Unit]
Description=FALSEDOOR FastAPI Backend
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/FALSEDOOR/server
ExecStart=/home/ubuntu/FALSEDOOR/server/venv/bin/python3 main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Enable:
```bash
sudo systemctl daemon-reload
sudo systemctl enable falsedoor-api
sudo systemctl start falsedoor-api
sudo systemctl status falsedoor-api
```

## If You Need to Retrain the Model on New Ubuntu

If your `.pkl` file is corrupted or you want fresh training data:

```bash
cd ~/FALSEDOOR

# Step 1: Extract features from cowrie.json
source cowrie-env/bin/activate
pip install pandas scikit-learn
python3 ml/feature_extraction.py

# Step 2: Train the Random Forest model
python3 ml/train_model.py
# Output: "Model saved to: ml/random_forest_model.pkl"

# Step 3: Restart FastAPI to pick up new model
sudo systemctl restart falsedoor-api
```
